# Repository Notes

- This is a single-package Vite + React app; install dependencies with `npm install`.
- Use `npm run dev` for local development, `npm run build` for production verification, and `npm run preview` to serve the production build locally.
- There are no configured test, lint, or typecheck scripts; `npm run build` is the available verification command.
- Vite starts at `index.html`, mounts React through `src/main.jsx`, and loads the app from `src/App.jsx`.
- `src/data/portfolio.js` is the source of truth for project descriptions, GitHub URLs, profile facts, and process content.
- Shared UI belongs in `src/components/`; route-level screens belong in `src/pages/`; global styling is in `src/styles.css`.
- Routing uses `BrowserRouter` with `/`, `/projects`, `/projects/:slug`, and a catch-all 404 route; keep project slugs synchronized with `src/data/portfolio.js`.
- The two completed project detail pages link to GitHub; `WalkersSandbox` intentionally remains an unlinked in-progress placeholder until its repository is ready.
- Contact profile URLs in `src/pages/HomePage.jsx` are still placeholders and must be replaced before publishing.
- `dist/` is generated by `npm run build`; do not edit its files directly.
